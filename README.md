# CSS Clock

A simple analogue clock built with HTML, CSS, and JavaScript. The hands show the current local time and update every second. The clock face, markers, and decorative border are created with HTML and CSS.

## Run

Open `index.html` in a web browser. No build step or dependencies are required.
An internet connection is needed to load the Orbitron font from Google Fonts.

## Technologies

- HTML
- CSS
- JavaScript
